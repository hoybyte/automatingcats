# Automating Cats

**A personal developer blog about building useful things, learning in public, and documenting the process.**

Automating Cats is my space to write about software development, IT automation, Linux, self-hosting, and the lessons learned along the way. Posts range from project walkthroughs and technical notes to occasional reflections on life outside the terminal.

**Website:** [automatingcats.net](https://automatingcats.net)

## About the project

This site is built with [Astro](https://astro.build/) and focuses on fast, readable, content-first pages. Articles are authored in Markdown and organized so I can keep a long-term archive of projects, experiments, fixes, and lessons learned.

Topics include:

- **Python and automation:** Scripts, APIs, data processing, and tools that reduce repetitive work.
- **Linux and development:** Omarchy, Fish, Neovim, Git, and terminal-based workflows.
- **Home lab and self-hosting:** Proxmox, Ubuntu Server, Docker, and private services.
- **Web development:** Building, deploying, and maintaining personal projects.
- **Notes and reflections:** What worked, what didn't, and what I learned.
